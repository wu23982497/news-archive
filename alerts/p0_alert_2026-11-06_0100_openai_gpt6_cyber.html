OpenAI 正式发布 GPT-6 Cyber：GPT-6 系列网络安全专用模型

事件时间：2026-11-06 约 01:00（上海时间）｜发现时间：2026-11-06 约 02:47（上海时间）

OpenAI 官网正式发布 GPT-6 Cyber，GPT-6 系列网络安全专用模型。ExploitGym 漏洞利用基准 48.5%，较 GPT-5.6 Cyber 的 32.1% 相对提升约 51%；在越权规避评估中 99.93% 的测试未超出授权范围（配合部署提示词时为 100%）。OpenAI 将其网络安全风险等级由 High 上调至 Critical。实测中已发现 81 个 Firefox 未知高危漏洞、为 948 个 Linux 内核漏洞开发出可工作利用（含 588 个此前未知）。初期仅向部分获批 Daybreak Red 客户开放 API 与 Codex 接入，数周内扩展至全部获批客户。

注意：本次发布的是网络安全专用型号，主力通用型号 GPT-6.2 仍未正式发布。时间说明：OpenAI RSS 标注的发布时间为 09:00 GMT，但路透社、The Register 等首批报道集中在 17:00–17:20 UTC（北京时间 11月6日 01:00–01:20），推断实际发布时间约为北京时间 11月6日 01:00，RSS 标注疑似将太平洋时间误标为 GMT；发现时间距实际发布约 1 小时 45 分钟。
